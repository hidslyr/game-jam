Puzzle game

Elements:

A puzzle with many connected piece in order, each piece has a color player need to fill color to clear piece one by one.
Piece has a number need to filled with same color.
All piece cleared, player win.

5 empty slots (make it flexible)

A grid board with baskets in the bottom (rows x colums), not required all cells has basket
- Baskets hold color amount.
- Player can pick basket to jump to the empty slot.
- Underneath basket automatically jump into first row.
- Player can only pick basket in the first row.
- Basket match with current order piece color, automatically fill in to piece.
- Empty basket go away, full-filled piece cleared.
- All empty slot used or no available move left, player lose.
